พัฒนาโดยทีม **THEEKRIT | ธีร์กฤติ โซลูชั่น**

เว็บแอปสำหรับผู้ใช้คนเดียว ทำงานในเครื่องผ่าน `http://127.0.0.1:8765` ข้อมูลเอกสารและแม่แบบเก็บใน SQLite ภายในเครื่อง แม่แบบรุ่นแรกใช้ Word ต้นฉบับที่อยู่ในโฟลเดอร์นี้ และนำเข้าแม่แบบสายช่างโยธา/สายพลาธิการผ่านหน้าเว็บได้

## ดาวน์โหลด ZIP สำหรับติดตั้ง

เปิดหน้า [Releases](https://github.com/artnetworkservice/-/releases/latest) แล้วดาวน์โหลดไฟล์ `QuotationLocal-v1.1.zip` ในหัวข้อ **Assets** ไฟล์นี้ใช้ชื่อภาษาอังกฤษและผ่านการตรวจสอบว่าแตกไฟล์ได้ครบ เหมาะกับ Windows มากกว่าการเลือก **Code > Download ZIP** ซึ่งจะได้ชื่อ `--main.zip`

## เปิดใช้งาน

ต้องมี **Python 3.11 ขึ้นไป** และ **LibreOffice** สำหรับ PDF การส่งออก Word ไม่ต้องใช้ LibreOffice ฟอนต์เอกสารควรติดตั้งให้ตรงกับ Word ต้นฉบับ โดยเฉพาะ TH SarabunPSK/Angsana New เพื่อให้ PDF จัดหน้าใกล้เคียงกันบนแต่ละเครื่อง

### macOS

1. ติดตั้ง Python 3.11 ขึ้นไปและ LibreOffice
2. คัดลอกโฟลเดอร์โปรเจกต์นี้ไปยังเครื่องใหม่ โดยเก็บ `frontend/dist` และไฟล์ Word ต้นฉบับไว้ ไม่ต้องคัดลอก `.venv`, `frontend/node_modules` หรือโฟลเดอร์ข้อมูล `.local-data*`
3. ดับเบิลคลิก `ระบบออกใบราคากลาง-macos.command` ครั้งแรกจะสร้าง `.venv` และติดตั้ง `python-docx` (ต้องต่ออินเทอร์เน็ตในครั้งแรก) จากนั้นเว็บจะเปิดเอง
4. ถ้าดับเบิลคลิกไม่ได้ ให้เปิด Terminal ในโฟลเดอร์นี้แล้วรัน `./ระบบออกใบราคากลาง-macos.command`

### Windows

1. ติดตั้ง Python 3.11 ขึ้นไปพร้อม Python Launcher (`py`) และ LibreOffice
2. คัดลอกโฟลเดอร์โปรเจกต์นี้ไปยังเครื่องใหม่ โดยเก็บ `frontend/dist` และไฟล์ Word ต้นฉบับไว้ ไม่ต้องคัดลอก `.venv`, `frontend/node_modules` หรือโฟลเดอร์ข้อมูล `.local-data*`
3. ดับเบิลคลิก `ระบบออกใบราคากลาง-windows.bat` ครั้งแรกจะสร้าง `.venv` และติดตั้ง `python-docx` (ต้องต่ออินเทอร์เน็ตในครั้งแรก) จากนั้นเว็บจะเปิดเอง

ทั้งสองระบบปิดโปรแกรมโดยปิดหน้าต่าง Terminal/Command Prompt ที่รันเซิร์ฟเวอร์ ข้อมูลที่บันทึกยังอยู่เมื่อเปิดใหม่

### ชุดโปรแกรมสำหรับย้ายเครื่องโดยไม่ต้องลง Python

ให้สร้างบนระบบปฏิบัติการปลายทาง เพราะไฟล์จาก macOS เปิดบน Windows ไม่ได้ และกลับกัน:

```sh
cd frontend && npm ci && npm run build && cd ..
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-build.txt
.venv/bin/python tools/build.py
```

บน Windows ให้ใช้ `py -3 -m venv .venv` และ `.venv\Scripts\python.exe` แทน `.venv/bin/python` คัดลอกทั้งโฟลเดอร์ `dist/QuotationLocal` ไปเครื่องปลายทาง แล้วเปิดไฟล์ `QuotationLocal` (`QuotationLocal.exe` บน Windows) ชุดโปรแกรมมีแม่แบบตัวอย่างใน `examples/` สำหรับอัปโหลดจากหน้าเว็บ ยังต้องมี LibreOffice และฟอนต์เอกสารเพื่อสร้าง PDF

## ใช้งานตั้งแต่ต้นจนดาวน์โหลด

1. เปิด **แม่แบบ** เลือกต้นแบบที่มี หรือกด **นำเข้า Word** แล้วเลือก `ต้นฉบับ สายช่างโยธา 70.docx` หรือ `ต้นฉบับ สายพลาธิการ 69.docx` ไฟล์ที่นำเข้าต้องมีหัวเอกสาร รายการตัวอย่าง ข้อสรุป และช่องลงชื่อตามโครงสร้างที่รองรับ
2. กด **สร้างเอกสาร** เลือกแม่แบบ กรอก `ที่` และ `วันที่` ส่วนช่อง `เรื่อง` จะแสดง `ราคากลางจัดซื้อพัสดุ` ไว้แล้ว ให้พิมพ์เฉพาะข้อความต่อท้าย ระบบจะเว้นวรรคและรวมสองส่วนใน Word/PDF
3. กรอกรายการ จำนวน หน่วย เลือก **เคยสั่งซื้อ** หรือ **มีราคาอ้างอิง** ตามกรณี ถ้าเคยซื้อ ให้ใส่เลขที่เอกสารและวันที่ในช่องเดียว เช่น `เอกสาร 1841/68 ลง 11 ก.ย. 68` พร้อมราคาเดิมต่อหน่วย
4. ใส่บริษัทและราคาต่อหน่วย เพิ่มบริษัทได้เรื่อย ๆ รายการใหม่จะคัดลอกชื่อบริษัทจากรายการแรกโดยเว้นราคาว่าง
5. กด **ตรวจข้อมูล** แล้ว **บันทึกฉบับร่าง** จากนั้นกด **ดูตัวอย่าง**, **Word**, หรือ **PDF**
6. ในหน้า **เอกสาร** ค้นหา แก้ไข คัดลอก ดาวน์โหลด หรือลบได้ การลบย้ายไปถังขยะและกู้คืนได้

เมื่อแก้แม่แบบ ระบบสร้างเวอร์ชั่นใหม่ เอกสารเก่ายังคงอ้างอิงเวอร์ชั่นเดิม การลบแม่แบบซ่อนจากรายการเลือก แต่ไม่ลบ Word ต้นฉบับของเอกสารเก่า

## สำรองและย้ายข้อมูล

กด **สำรองข้อมูล** เพื่อดาวน์โหลด ZIP ที่มีฐานข้อมูลและแม่แบบ แล้วนำ ZIP ไปยังเครื่องใหม่ กด **กู้คืนข้อมูล** เพื่อแทนข้อมูลในเครื่องนั้น ควรสำรองข้อมูลปัจจุบันก่อนกู้คืน ข้อมูลปกติอยู่ที่ `~/Library/Application Support/QuotationLocal` บน macOS และ `%LOCALAPPDATA%\QuotationLocal` บน Windows กำหนดตำแหน่งเองได้ด้วยตัวแปร `QUOTATION_DATA_DIR`

## ข้อจำกัดที่ต้องตัดสินใจก่อนใช้เอกสารจริง

- หากราคาเคยซื้อต่ำกว่าราคาเสนอทุกบริษัท ระบบหยุดส่งออกและขอให้กำหนดกติกาเลือกราคา
- หากหลายบริษัทเสนอราคาต่ำสุดเท่ากัน หรือไม่ได้เสนอในบางรายการ ยังต้องยืนยันข้อความสรุปและจำนวนบริษัทที่ต้องการ
- จำนวนครั้งก่อนเก็บในข้อมูล แต่แม่แบบเดิมแสดงจำนวนที่จะซื้อครั้งนี้ในบรรทัดราคาเดิม จึงยังไม่พิมพ์จำนวนครั้งก่อนใน Word
- ข้อความสรุปตามแม่แบบระบุว่าราคารวม VAT และค่าใช้จ่ายแล้ว ระบบไม่บวก VAT เพิ่ม ผู้ใช้ต้องยืนยันว่าราคาที่กรอกเป็นราคาสุทธิตามข้อความนี้
- การนำเข้า Word รองรับโครงสร้างของไฟล์ตัวอย่างที่ให้มา หากแม่แบบใหม่มีตำแหน่งรายการหรือสรุปต่างจากนี้ ระบบจะแจ้งว่าไม่รองรับ
- การจัดหน้า PDF ขึ้นกับฟอนต์และ LibreOffice บนเครื่องปลายทาง ควรตรวจพรีวิวก่อนใช้งานจริง
